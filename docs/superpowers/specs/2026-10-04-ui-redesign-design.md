# 분석 화면 디자인 개편 설계

- 작성일: 2026-10-04
- 상태: 검토 대기
- 범위: 분석 대시보드(명세 `2026-10-03-analysis-dashboard-design.md`)의 화면 톤과 대표 구성을 개편한다. 데이터·API는 바꾸지 않는다.
- 참고: Oxford Economics Global Cities Index "Compare your city" 화면의 디자인 톤(벤치마킹이며 로고·문구·이미지는 가져오지 않는다)

## 1. 목표와 결정 사항

### 1.1 목표
지금 화면(회색 톤, 얇은 테두리 카드, 시스템 글꼴, 작은 제목)을 참고 사이트의 톤으로 바꾸고, 그 사이트의 대표 구성 몇 가지를 지도·대시보드·추이 화면에 들여온다.

참고 사이트에서 가져올 톤:
- 짙은 남색을 제목·선택 상태·표 머리줄에 쓰고, 아주 옅은 회청색 배경 위에 흰 카드를 올린다.
- 모서리를 크게 둥글린 카드, 옅은 그림자, 넉넉한 여백
- 크고 굵은 남색 제목과 회색 한 줄 설명
- 범주색 점이 붙은 알약 버튼(선택 시 남색 채움)
- `#순위`·굵은 이름·회색 보조 문구·색 점으로 된 순위 목록
- 남색 머리줄, 정렬 화살표, 값 옆 짧은 막대가 있는 비교표, 하단 요약 줄
- 지도와 순위 목록을 좌우 카드로 배치

### 1.2 결정 사항
| 항목 | 결정 |
|---|---|
| 범위 | 톤 + 대표 구성 차용. 정보 구조(내비게이션 형태, 대시보드 항목)는 유지 |
| 색의 의미 | 지금 규칙 유지: 크기 = 남색 한 가지 색의 진하기, 증감 = 파랑↔회색↔빨강(상승 = 빨강). 참고 사이트의 초록→빨강 신호등은 쓰지 않는다(집값·거래량은 좋고 나쁨이 아니고, 색약에 불리) |
| 어두운 테마 | 유지. 새 톤의 어두운 짝을 정의 |
| 글꼴 | Pretendard(OFL) 가변 글꼴 분할 woff2를 저장소에 넣어 직접 제공 |
| 지도 순위 영역 | 지도 오른쪽 순위 목록 카드 + 지도 아래 다지표 비교표 |
| 구현 방식 | 인라인 스타일을 공통 스타일 파일로 분리하고 재사용 부품(CSS 클래스·Jinja 매크로)으로 구성 |

### 1.3 범위 밖
- 지구본 표시, 지역 비교 체크박스(추이 화면이 맡음)
- 새 데이터·새 API·URL 상태 키 변경
- 내비게이션 구조 변경, 새 화면 추가

### 1.4 성공 기준
- 모든 화면이 새 톤(색·글꼴·카드·알약·표)으로 그려지고, 밝은·어두운 테마 모두에서 본문 대비가 WCAG AA 이상이다.
- 지도 화면에서 순위 목록 선택 ↔ 지도 강조가 연동되고, 비교표가 열별로 정렬된다.
- 기존 URL(`/map?level=…&metric=…` 등)과 북마크가 그대로 동작한다.
- 폭 375px에서 가로 스크롤 없이 1열로 보인다(비교표는 표 안에서만 가로 스크롤).
- 외부 스타일시트가 없고 외부 스크립트는 ECharts 하나뿐이다.
- 기존 테스트가 모두 통과한다.

## 2. 시각 체계

### 2.1 색 토큰
`static/css/app.css`의 `:root`에 정의하고, 어두운 테마는 `@media (prefers-color-scheme: dark)`에서 다시 정의한다. 차트는 지금처럼 `App.css('--토큰')`으로 읽는다.

밝은 테마(값은 구현 때 대비를 재서 미세 조정할 수 있다):
| 토큰 | 값 | 용도 |
|---|---|---|
| `--bg` | `#f3f6fa` | 페이지 배경(옅은 회청색) |
| `--card` | `#ffffff` | 카드 |
| `--ink` | `#0b2a55` | 제목·선택 상태·표 머리줄·주요 버튼(남색) |
| `--text` | `#1c2a3d` | 본문 |
| `--muted` | `#5b6b80` | 보조 문구 |
| `--line` | `#e3e8ef` | 구분선 |
| `--shadow` | `0 1px 2px rgba(11,42,85,.06), 0 4px 16px rgba(11,42,85,.06)` | 카드 그림자 |
| `--accent` | `--ink`와 같음 | 링크·강조 |

어두운 테마: `--bg` 짙은 남색(약 `#0d1726`), `--card` 한 단계 밝은 남색(약 `#16233a`), `--ink`·`--accent` 밝은 파랑(약 `#7fb0ff`), `--text` 밝은 회백색, 그림자는 약하게.

기존 차트 토큰은 의미를 유지한 채 값만 조정한다.
- `--seq-100`~`--seq-700`: 옅은 하늘색 → 짙은 남색 7단계(마지막 단계가 `--ink`에 가깝게)
- `--div-*`: 파랑↔회색↔빨강 유지
- `--series-1`~`--series-8`: 지역 비교용 8색 유지(지역에 붙음)
- `--grid`, `--axis`, `--provisional`: 새 배경에 맞게 조정

지표 고유색(알약의 점, 비교표 막대). 지역 비교 8색과 별개다.
| 토큰 | 지표 |
|---|---|
| `--m-price` | 중위 거래가 |
| `--m-ppm2` | ㎡당 중위가 |
| `--m-count` | 거래량 |
| `--m-yoy` | 전년 대비(증감 열은 막대 색 대신 증감 색을 쓴다) |

### 2.2 글꼴
- Pretendard 가변 글꼴 분할 판(woff2 여러 개 + `@font-face` CSS, unicode-range로 쓰인 글자 묶음만 내려받음)을 `static/fonts/pretendard/`에 두고 `OFL.txt`를 함께 넣는다.
- `font-family: "Pretendard Variable", Pretendard, -apple-system, "Malgun Gothic", sans-serif`
- 표·숫자에는 `font-variant-numeric: tabular-nums`

### 2.3 글자 크기
| 요소 | 크기·굵기 |
|---|---|
| 화면 제목 | 30px, 700, `--ink` (좁은 화면 24px) |
| 한 줄 설명 | 15px, 400, `--muted` |
| 카드 제목 | 18px, 700, `--ink` |
| 본문 | 15px |
| 표 본문 | 14px |
| 표 머리줄 | 12px, 700, 자간 넓게, 흰 글자 on `--ink` |
| 보조 문구·범례 | 13px, `--muted` |

### 2.4 부품
| 부품 | 클래스(예) | 모양 |
|---|---|---|
| 머리 영역 | `.page-head` | 제목 + 한 줄 설명 + 작은 회색 상태 줄(출처·수집 상태) |
| 카드 | `.card`, `.card-title` | 반경 16px, 안쪽 여백 20–24px, `--shadow`, 테두리 없음 |
| 조건 막대 | `.filters` | 카드 안 한 줄, 좁으면 줄바꿈 |
| 알약 묶음 | `.pills`, `.pill`, `.pill .dot` | `button` + `aria-pressed`. 선택 시 남색 채움·흰 글자, 범주색 점 |
| 입력·선택 상자 | 기본 `input`·`select` | 높이 44px, 반경 10px |
| 순위 목록 | `.rank-list`, `.rank-item` | `#순위`, 굵은 이름(`--ink`), 회색 보조 문구, 오른쪽 값·색 점. 선택 항목 강조 |
| 비교표 | `.data-table` | 남색 머리줄, 정렬 화살표(`aria-sort`), 행 구분선, 하단 요약 줄 |
| 막대 셀 | `.bar-cell` | 값 숫자 + 짧은 막대(열 최댓값 대비 비율). 증감 열은 가운데에서 좌우로 |
| 배지 | `.badge`, `.badge.up`, `.badge.down` | 증감·상태 표시(색 + 부호·문구 함께) |
| 타일 | `.tile` | 큰 숫자 카드 |
| 내비게이션 | `nav` | 상단 가로 막대, 현재 화면에 남색 밑줄 |

## 3. 화면별 구성

### 3.1 공통
- 모든 화면 위에 머리 영역(제목 + 한 줄 설명)을 둔다. `base.html`에 `page_title`, `page_desc` 블록을 둔다.
- 지금 상단의 출처·수집 상태 줄은 머리 영역 아래 작은 회색 줄로 옮긴다. 하단의 경계 출처(CC BY 조건)는 그대로 둔다.
- 기간·면적·지표 선택은 카드 안 조건 막대로 묶는다. 지표와 면적 구간은 알약으로 바꾼다.

### 3.2 대시보드 `/`
- 요약 타일 3개: 큰 숫자 카드, 전년 대비는 증감 배지
- 거래량·중위가 차트 2개: 넓은 화면 2열 카드, 좁은 화면 1열
- 상승·하락 시군구: 순위 목록 스타일(`#1`, 지역명, 상위 지역, 값, 증감 배지). 지역명을 누르면 추이 화면

### 3.3 지도 `/map`
- 조건 막대: 지표 알약 5개(중위가, ㎡당가, 거래량, 중위가 전년 대비, 거래량 전년 대비), 면적 알약, 기간, 지역 경로(전국 › 시도 › 시군구)
- 좌우 카드: 왼쪽 지도, 오른쪽 순위 목록 카드
  - 순위 목록 위: 지역 검색(이미 받은 목록 안에서 거름), 색 막대 범례(크기 지표 "낮음 ↔ 높음", 증감 지표 "하락 ↔ 상승")
  - 항목: `#순위`, 지역명, 상위 지역, 값, 색 점(지도 색과 같음)
  - 항목 선택 → 지도에서 해당 지역 강조, 목록 카드 위에 미니 추이, 하위 단계가 있으면 "하위 지역 보기" 버튼
  - 지도에서 지역을 누르면 지금처럼 하위 단계로 내려간다(동작 유지)
- 지도 아래 비교표
  - 열: 지역, 중위가, ㎡당가, 거래량, 중위가 전년 대비, 거래량 전년 대비
  - 막대 셀: 크기 열은 열 최댓값 대비 길이·지표색, 증감 열은 가운데 기준 좌우·증감 색
  - 열 머리 클릭 정렬(오름·내림 전환), 빈 값은 항상 맨 아래
  - 지역명 클릭 → `/trends?regions=<level>:<code>&band=<band>`
  - 하단 요약 줄: "N개 지역 · 기간 · 가격은 월별 중위가의 거래량 가중평균 · 전년 대비 기간", 읍면동이면 커버리지
- 데이터는 지금 받는 `/api/map` 응답만 쓴다.

### 3.4 추이 `/trends`
- 지역 선택·칩은 유지, 칩 모양만 새 톤
- 지표·면적 구간을 알약으로
- 이동평균·지수·표 보기·PNG 저장은 차트 카드 오른쪽 위의 작은 버튼 묶음
- 표 보기의 표는 `.data-table` 스타일

### 3.5 단지 검색 `/complexes` · 상세 `/complexes/<id>`
- 검색: 큰 입력 상자 + 지역 코드 입력, 결과는 `.data-table`(단지명 굵은 남색, 지역 회색 보조 문구)
- 상세: 머리 영역에 단지명(제목)과 지역·건축년도·좌표 상태 배지, 차트 3개는 카드, 거래 표는 `.data-table`(해제 거래 취소선 유지)

### 3.6 추출 `/export`
- 카드 하나 안에 단계별 배치: 대상·형식·면적은 알약, 지역·기간은 선택 상자, 큰 남색 내려받기 버튼
- 알약의 선택값은 같은 이름의 숨은 입력(`target`, `band`)과 형식 값에 넣어 폼으로 보낸다. 기존 60개월 사전 검사·서버 400 유지

### 3.7 거래 목록 `/trades` · 수집 현황 `/status` · 로그인
- 구성 유지, 새 부품(카드·표·타일·버튼)으로만 바꾼다.

## 4. 파일 구조

| 파일 | 내용 |
|---|---|
| `static/css/app.css` (새로) | 토큰(밝은·어두운), 기본 요소, 부품 |
| `static/fonts/pretendard/` (새로) | 분할 woff2, `pretendard.css`(`@font-face`), `OFL.txt` |
| `templates/base.html` | 인라인 `<style>` 제거, CSS 2개 연결, 머리 영역 블록, 내비게이션·상태 줄 재배치 |
| `templates/_ui.html` (새로) | Jinja 매크로: `page_head`, `pills`, `rank_list` 틀 등 |
| 각 화면 템플릿 | 새 부품으로 재구성 |
| `static/js/common.js` | 알약 공통 처리(선택 상태·`aria-pressed`·URL 상태 연동), 막대 셀 도우미 |
| `static/js/map.js` | 순위 목록 카드(검색·범례·선택 강조), 비교표(정렬·막대), 지도↔목록 연동 |
| `static/js/dashboard.js`, `trends.js`, `export.js` | 알약·새 목록 스타일 반영 |

## 5. 지킬 제약
- 기존 계획 3의 차트 규칙: 이중 축 금지, 지역 비교 8색은 지역에 붙음, 계열 2개 이상이면 범례, 모든 차트에 툴팁, 글자는 글자 색 토큰
- 색만으로 정보를 전하지 않는다: 색 점·막대·배지에는 숫자나 부호·문구를 함께 표시
- 알약은 `button`+`aria-pressed`, 정렬 머리는 `aria-sort`, 키보드로 조작 가능
- API, URL 상태 키(`regions`, `metric`, `band`, `from`, `to`, `ma`, `idx`, `level`, `parent`, `q`, `region`)를 바꾸지 않는다
- 외부 스크립트는 cdnjs ECharts 하나, 외부 스타일시트 없음
- 경계 출처 표시(CC BY)를 모든 화면에 유지

- 브라우저 확인(시드 DB `molit_seed`, 경계 `2026-10`): 화면마다 밝은·어두운 테마, 폭 375px, 콘솔 오류 없음, 스크린샷
  - 지도: 순위 목록 선택 ↔ 지도 강조, 비교표 정렬, 증감 열 양방향 막대, 검색
